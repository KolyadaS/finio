## Finio

Адаптивная верстка лендинга финансового сервиса с акцентом на чистую структуру и аккуратный UI.

🔗 Демо: https://kolyadas.github.io/finio/

### Цель проекта
Практика современной фронтенд-разработки: создание адаптивного интерфейса с продуманной структурой и переиспользуемыми стилями.

### Что реализовано
- Адаптивная верстка под мобильные, планшетные и десктопные устройства
- Семантическая HTML-разметка
- Карусель с отзывами
- Базовые интерактивные состояния (hover)

### Стек
- HTML5 (семантическая разметка)
- CSS3 (Flexbox, медиа-запросы)
- БЭМ для организации стилей
